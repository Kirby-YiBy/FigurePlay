FigurePlay 使用说明

快速上手

  1. 左侧选择「行 × 列」，例如 3 行 × 2 列 或 1 行 × 6 列；也可用「单栏 / 双栏模板」一键套用期刊版式。
  2. 点击预览中的空子图会弹出「粘贴小画布」：按 Ctrl+V 直接粘贴 MATLAB 图窗 / 截图，也可以拖入文件或选择本地图片。
  3. 按住 Ctrl/Shift 点击多个子图可多选，再合并成跨列大图（如 2×3 首行跨 3 列），或批量套用编号。
  4. 顶部「＋ 新页 / 复制页 / 删除页」可建立多页图集；双击页签改名，导出时可选当前页或全部页。
  5. 配置模板：左侧「配置模板」可把当前网格、编号、字体、间距和导出设置保存到本机，也可导出/导入 .figureplay.json 到其他电脑；配置不含图片，导入时会显示名称、说明和参数摘要。
  6. 界面外观：顶栏调色板按钮可选择浅色 / 深色 / 跟随系统，并提供蓝、靛蓝、青绿、翠绿、紫罗兰、玫红、琥珀主题色；切换只改 CSS 变量，不会重绘图稿，也不影响导出图形颜色。
  7. 网格行/列可直接输入（1–500，单页最多 2500 格）；编号超出页面时会自动加页距，也可关闭自动后手动填四边页距。列/行间距支持负值（-50～80 mm），可抵消图片自带的白边。
  8. 导出时可勾选「自动裁剪 PDF 白边」（按实际内容墨迹裁剪，类似 pdfcrop；0 mm 会保留约 1 mm 防裁字安全边距）；滑块旁的百分比/数值框都可以直接输入。
  9. 左侧「子图分组」可把若干子图编为一组，每组使用独立编号方案与起始号（如 A 组 (a)(b)、B 组 (i)(ii)）。
  10. 在右侧设置编号样式、统一位置、字体字号；最后选择导出格式与 DPI。改错了随时 Ctrl+Z 撤销。

MATLAB 图窗快速导入

  • 在 MATLAB 图窗中选择 Edit → Copy Figure，然后在 FigurePlay 的粘贴小画布中按 Ctrl+V。
  • MATLAB 默认复制的是 EMF 图元，普通浏览器可能无法直接识别：可把 MATLAB 的 Copy Options → Clipboard format 设为 Bitmap，或使用桌面版 FigurePlay.exe（自动将 EMF 转为高清 PNG）。
  • 桌面版支持直接拖入 / 选择 .fig 文件（需本机安装 MATLAB）：会自动调用 MATLAB 后台导出为高清 PNG，再填入子图。
  • 桌面版还提供「读取系统剪贴板」按钮，读取后可直接预览确认。

多页与分组

  • 每个图页有独立的网格、子图、编号与分组；切换页签不会影响其它页。
  • 导出范围为「全部页」时：PDF 生成一个多页 PDF；PNG / JPG / SVG 会打包成 ZIP（每页一个文件）。
  • 分组会显示彩色虚线框与组名（仅预览，不进入导出）；组内编号顺序仍按全局「编号顺序」计算。

快捷键

  • Ctrl + Z：撤销；Ctrl + Shift + Z / Ctrl + Y：重做
  • Ctrl + V：打开粘贴小画布并粘贴剪贴板图片
  • Ctrl / Shift + 点击子图：多选（用于合并、批量编号、分组）
  • Ctrl + PageUp / PageDown：切换图页
  • Delete / Backspace：清除选中的子图图片
  • Esc：取消选中 / 关闭弹窗
  • 选中子图后：方向键微调位置，Shift + 方向键快速移动，滚轮缩放图片
  • 双击子图：打开粘贴/替换小画布

导出格式

  • PNG：无损位图，可透明背景，适合直接投稿。
  • JPG：体积小，不支持透明（背景使用当前背景色），可调质量。
  • SVG：矢量格式，编号文字可在 Illustrator / Inkscape 中继续编辑。
  • PDF：按毫米尺寸生成 PDF，内嵌所选 DPI 的高分辨率位图；多页工程可一次输出多页 PDF。
  • 矢量 PDF（桌面版）：从 MATLAB「Copy Figure」粘贴的 EMF 会保留原始矢量数据；桌面版会用本机 PowerPoint 排版引擎输出矢量 PDF，线条和文字放大不会出现马赛克。首次启动 PowerPoint 约 20–40 秒，之后会复用会话，速度会明显加快；没有 PowerPoint 或使用了裁剪/旋转/偏移等复杂变换时，会自动回退为高分辨率位图 PDF。
  • 保存位置：勾选「导出时选择保存位置」后，Chrome / Edge 会弹出另存为窗口；不支持时仍下载到默认下载目录。

支持图片

PNG、JPG、WebP、GIF（首帧）、BMP、SVG、TIFF，以及通过粘贴小画布导入的剪贴板图片；桌面版额外支持 MATLAB .fig。所有处理均在本地完成，不会上传任何文件。
